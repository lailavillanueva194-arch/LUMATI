# LUMATI
Lumati es un juego 2D de vista aérea para niños que quieren descubrir el espacio, la Luna y Marte. El jugador empieza como astronauta varado en la Luna y debe sobrevivir cultivando alimento y organizando su base. Aprende a trabajar con electricidad y a armar circuitos básicos, además de organización, exploración de zonas y orientación.
